# M Scouting website

Static informational website (HTML, CSS, JavaScript). No server, no keys, no secrets.

## Put it online (GitHub Pages)
1. On GitHub click **New repository**. Name it `m-scouting-website`. Keep it **Public**. Create it.
2. Click **uploading an existing file**. Drag in EVERYTHING inside this folder (all .html files, `css`, `js`, `assets`, `.nojekyll`). Click **Commit changes**.
3. Go to **Settings -> Pages**. Under **Branch** choose `main` and folder `/ (root)`. Click **Save**.
4. Wait 1-2 minutes. Your website address will be:
   `https://adeli-pix.github.io/m-scouting-website/`

## Before you publish
Search the pages for yellow boxes (placeholders): contact email, phone, address, hours, and the legal [confirm] items in privacy.html, terms.html and refund.html. Replace them with real information.
